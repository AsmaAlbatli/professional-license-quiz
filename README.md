# منصة اختبار الرخصة المهنية - الإشراف التربوي

اختبار تدريبي تفاعلي لتخصص الإشراف التربوي وفق معايير هيئة تقويم التعليم والتدريب (إتقان). يتضمن بنك أسئلة موزّعًا على المجالات الأربعة الرئيسية، مع تصحيح فوري، تغذية راجعة، شريط تقدّم، نتيجة نهائية، ومراجعة للإجابات.

## الاستخدام

افتح `index.html` في أي متصفح حديث، أو استخدم رابط GitHub Pages.
